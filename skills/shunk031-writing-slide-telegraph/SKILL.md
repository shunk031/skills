# 技術スライドのテレグラフ文体

- 最初に `shunk031-writing-kosshi` skill を読み、主張と根拠の骨子を作る
  - 論点の階層、事実保持、引用、不足情報の扱いは同 skill に委ねる
  - この skill は、骨子を技術・論文紹介スライドへ分節し、各スライドの文章へ圧縮する層を担う
- デッキ全体は、聞き手が内容を追う順に組み替える
  - 論文紹介では、表紙・自己紹介の後に `本論文の選定理由` を置き、発表者が何に注目したかを先に示してよい
  - 本編は、導入・関連研究・手法・実験設定・結果・議論と制限・今後の展望・まとめなどから、素材に必要な節だけを選ぶ
  - サーベイでは、全体像や分類軸を先に示し、分類ごとの説明、節ごとの小括、未解決課題、今後の方向性へ進める
  - 論文の章順を写すのではなく、選定理由で示した問いに答える流れを優先する
- 一枚には一つの説明上の役割を持たせ、タイトルで現在地とその枚の対象を示す
  - 現在の文体では `<節> | <その枚の対象>` を基本とし、短いラベルには `:` も使える
  - 一つの対象を複数枚で見せる場合は `<節> 1/N | <対象>` や `<節> | <対象> 1/N` のように連番を付ける
  - 段階表示では本文を保ったまま図や注釈だけを追加することがあるため、同じ本文を別の論点として数えない
  - 長いデッキでは、全体の分類や現在の節を示す案内を反復し、節の切り替わりで小括を置いてよい
- 各スライドは、独立したメッセージラインを一文だけ置く型に固定せず、必要な小ブロックを積み重ねる
  - タイトルの下に、`主要な結果`、`結果の解釈`、`現状と課題`、`将来方向` など、その枚に必要な短い小見出しを置く
  - 小ブロックは、小見出し、主張・分類・手順、根拠・条件・具体化、必要に応じた定義・例の順に深める
  - 主張、補足、詳細の階層ごとにインデントを一段深くし、箇条書き記号の字形は文体の要件にしない
  - 推論を閉じる必要がある枚だけ、`➜`、`示唆`、`結果の解釈`、`本研究領域の要点` などで局所的な着地を置く
  - タイトル、各小見出し、必要な着地だけを拾っても、デッキの論旨が追えるか確認する
- 論文が述べた事実と発表者の読みを区別する
  - 素材にある発表者の補足、解釈、疑問は `本資料では`、`結果の解釈`、`気になったところ`、疑問形などで見分けられるようにする
  - 選定理由や余白の注釈では口語や感情表現も使えるが、事実説明の中心へは持ち込まない
- `shunk031-writing-kosshi` skill の近接引用を、スライドでは引用対象の直後に短い角括弧書式で表す
  - 基本形は `手法名 [第一著者+ 会議・媒体’YY]` とし、素材に会議・媒体がなければ補わない
  - 一つの文に複数の手法があれば各手法の直後へ個別に付け、一つの主張を複数文献が支える場合だけ同じ角括弧内にまとめる
  - 図版の引用は `From [第一著者+ 会議・媒体’YY]` や `図は [第一著者+ 会議・媒体’YY] より引用` として図の近くに置く
  - 引用を文末やスライド末尾へまとめて移さない
- 各行は、視線を止めずに意味を取れるテレグラフ文体へ圧縮する
  - 回収できる主語、助詞、コピュラを省き、名詞句と短い節を自然に混ぜる
  - 一行には一つの主張、関係、条件、数値のまとまりを置く
  - 専門語は初出時に日本語と英語名・略称を対応させ、以降は略称を使う
  - タイトルと小見出しも、箇条書きと同じく行末に句点 `。` を付けない
- 記号は、語句間の関係を短く示せる場合だけ使う
  - `➜` は直前の内容から論旨を一段進め、前提から帰結、問題から次の焦点、比較から解釈へ移る箇所に置く
  - `vs.` は対比、`:` はラベルと内容、`/` は並列・併記、`|` は節と局所テーマの境界に使う
  - `👍`、`🤔` などは発表者の評価を明示する場合だけ使い、装飾目的では使わない
  - 記号だけで関係が曖昧になる場合は、短い日本語で書く
- この skill はスライドに載せる文章と構成を扱う
  - 配色、レイアウト、図版選定、アニメーション実装、PPTX や PDF の生成は対象外

## 例

入力:

```markdown
新しい活性化解釈手法を紹介する。既存手法は教師なし説明か自然言語出力の片方に重点を置く。提案手法は自然言語をボトルネックにして活性化を再構成し、両方を狙う。再構成性能は高いが、説明には入力文脈と食い違う作話が含まれる。監査では決定的証拠ではなく仮説生成に使うべきだと発表者は考えている。
```

出力:

```markdown
## 関連研究 | 既存手法の位置づけ

既存手法の二分

- 教師なしで説明を生成
- 直接読める自然言語を出力
- 多くの手法はどちらか一方に重点

提案手法の狙い

- 自然言語ボトルネックから活性化を再構成
  - 教師なし説明と自然言語出力の両立

## 議論と制限 | 再構成性能と説明の信頼性

確認できた強み

- 高い活性化再構成性能

残る限界

- 入力文脈と食い違う作話を含む場合あり

実践上の位置づけ

- 発表者の解釈: 決定的証拠ではなく、監査仮説の生成に使う
```
