# Verify local prose

Try to refute the prose after the global structure is settled. Flag unclear sentence order, broken transitions, inconsistent terms, undefined technical language, mechanical errors, AI-tell phrasing, and explanations or prompt residue that only the originating conversation supports. Quote the smallest evidence that identifies each finding.

Check evidence by kind. Published works need a footnote marker attached directly to the named entity and a definition with authors or organization, title, venue, year, and a DOI, arXiv, or ACL URL; resources such as repositories, code or data files, documentation, dataset cards, and licenses need inline links. Within a paragraph, table row, or contiguous list, mark each entity once at most, share one marker across sibling entities, ensure every cited entity has a marker somewhere, and reject a duplicate `Paper:` entry for a work already marked in that passage. In-repository links must be relative or commit-pinned, never branch-qualified.

Check that abbreviations are expanded at first use unless they are universally understood tokens or proper names, uncertainty uses plain-language hedges, durable caveats state their scope or condition, and evaluative claims name their criterion or use a hedge. Check that fragment bullets omit periods, sentence bullets use punctuation, and each list follows one convention.

Specimen: "sentence structure and grammar."
