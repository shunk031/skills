# Report

Put the answer and its consequence in the first section. Separate the evidence needed to trust the answer from audit details needed to reproduce it. Include an honest scope or limitation note when the evidence does not support a broader claim. Use claim lines with telegraphic support for visible bullets.

Describe a procedure in prose with a descriptive source link when the report is explaining it; use a step list only when the reader must execute the procedure.

Owner-authored specimen: 「item 数は 200 である。」
