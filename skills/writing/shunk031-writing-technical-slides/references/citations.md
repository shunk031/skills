# 引用と出典

論文が述べた事実と発表者の解釈を区別する。発表者の補足・解釈・疑問は `本資料では`、`結果の解釈`、`気になったところ`、疑問形などで分かるようにする。`👍`、`🤔` などは発表者の評価を示す場合だけ使う。

## 本文中の短い引用

- 論文由来の手法名・主張・比較対象・定量結果・図は、原則として対象の直後または図の近くに短い角括弧書式で示す。
- 基本形は `手法名 [第一著者+ 会議・媒体’YY]` とする。素材に会議・媒体がない場合は補わない。
- 一つの文に複数の手法があれば各手法の直後へ個別に付け、一つの主張を複数文献が支える場合だけ同じ角括弧内にまとめる。例は `QueryRank [Yamada+ ACL’25]`、`NDCG: 0.412 [Yamada+ ACL’25, Table 2]`。
- 図版の引用は `Figure from [第一著者+ 会議・媒体’YY]` や `図は [第一著者+ 会議・媒体’YY] より引用` として図の近くに置く。
- 発表者が原論文にない出典を補う場合は、原論文の出典と区別して追加情報源であることを明記する。

## スライド末尾のリンク付き出典

各スライドの末尾に `**出典**` を置き、参照した論文へ移動できる Markdown リンクを記す。本文中の近接引用とリンク付き出典は併用し、引用を文末やスライド末尾へ集約しない。

- 論文に arXiv 版がある場合は、原則として arXiv の abstract ページを使う。ない場合や公式公開ページを使う明確な理由がある場合は、CVF、OpenReview、ACL Anthology、出版社などの公式論文ページを使う。
- Project Page はデモ、コード、追加資料を参照するために使い、論文本体の代替にはしない。
- 可能なら出典ラベルに対象の section、figure、table、equation を含める。関連研究を列挙するスライドでは、各論文のリンクを個別に解決する。
- 多くの図や数式を引用する場合も、個別の手法や図の出典を省かない。

## 例

以下は架空の手法と文献を使った例である。

```markdown
## 実験結果 | 精度向上とレイテンシの増加

- QueryRank: 0.412 [Yamada+ ACL’25, Table 2]

➜ QueryRank は精度で優位・推論コストとの釣り合いは未検証

気になったところ

- 発表者の見解: 精度向上とレイテンシ増加を同じ運用条件で追加評価したい

**出典**

- [Yamada+ arXiv’25, Table 2](https://arxiv.org/abs/<arXiv-id>)
```
