# 日本語執筆スキルの選択

エージェントが依頼の目的と修正範囲を判断し、下表から担当スキルを選ぶ。既定は構成から読みやすく整理する方針とする。このスキルは選択を担当し、文体規則や校正手順は担当スキルに委ねる。

## 選び方

利用者がスキル、修正範囲、文体、出力形式を指定している場合は、その指定を優先する。複数のスキルが候補になっても、本文を読む前に担当を選び、選んだスキルと必要な依存先だけを読む。

| 依頼の目的・修正範囲                                                                                          | 担当スキル                                |
| ------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| 新規執筆、構成や論旨の整理、修正範囲を指定しない「読みやすくして」「自然な日本語にして」「AI っぽさを直して」 | `natural-japanese` skill                  |
| 原文の口調・構成・熱量を残す推敲、「最小限の修正で」「言い回しをなるべく残して」                              | `yomiyasu` skill                          |
| 主張と根拠を骨子箇条書きに整理する                                                                            | `shunk031-writing-kosshi` skill           |
| 骨子を短い箇条書き・テレグラフ文体にする。形式指定のないレポート新規作成も既存の運用に合わせてこちらを選ぶ    | `shunk031-writing-telegraph` skill        |
| 技術解説・論文紹介のスライド本文と構成を作る                                                                  | `shunk031-writing-technical-slides` skill |
| 書き換えずに文章の自然さを診断・採点する、書き手の文体をプロファイル化する                                    | `natural-japanese` skill の該当モード     |

「段落のまま」「です・ます調を維持」「本文だけ」のような指定は担当スキルにも引き継ぐ。レポートの既存本文を推敲する依頼は、レポートという名称だけでテレグラフ文体に変換せず、修正範囲で選ぶ。スライドのファイル生成や視覚デザインは、この選択表とは別に必要な制作手段を使う。

原文があるという理由だけで `yomiyasu` skill を選ばない。指定が曖昧でも通常は `natural-japanese` skill で進め、構成変更と原文保持の指定が食い違う場合だけ利用者に確認する。

## 読み込みと実行

- 担当スキルはセッションのスキル一覧から名前で探し、実際の `SKILL.md` を読む。関連ファイルとスクリプトはその配置先を基準に解決する。
- 担当が未導入なら、利用できないスキル名を伝える。指定されたスキルを使ったと装ったり、その場で無断インストールしたりしない。代替が必要な場合は違いを説明して利用者に選んでもらう。
- 選択後は担当スキルの必要な参照、校正、検査を実行する。一般的な推敲は既定の通常モードから始め、選択しただけで作業を終えない。
- 骨子、テレグラフ文体、技術スライドの依存関係と利用者への確認手順は、各スキルの定義に従う。依存先で文体を整えた後に、一般向けの校正スキルで再び全文を書き換えない。
- 利用者が工程の組み合わせを指定した場合は、各工程の対象と変更範囲を分ける。毎回すべての校正スキルを順番に適用する工程にはしない。

## 競合を避ける範囲

`natural-japanese` skill と `yomiyasu` skill は同じ本文の主担当として同時に適用しない。前者で構成を整理した後に、後者を必須の仕上げ工程として追加する運用もしない。両方を比較する依頼では、同じ原文から別々の案を作る。

`unslop` skill などが上位の指示で適用される場合は、その指示に従う。担当スキルを追加することと、別の全文改稿を重ねることを区別し、数値、引用、断定の強さ、指定された箇条書きや文体を校正の都合で変えない。

このスキルはエージェントの選択手順であり、ホストの自動選択を無効化したり、既に読み込まれた指示をコンテキストから消したりする機能は持たない。上位の指示と利用者の指定が両立しない場合は、その制約を伝える。設定の無効化や変更は、利用者が求めた場合に対象を確認して行う。

選択基準を見直す際は、各スキルの現行の指示を確認する。単一の文章による比較結果を、あらゆる文章での優劣として固定しない。
