# Markdown 草稿の形式

ユーザーが PPTX、PDF などへのファイル化を明示しない限り、スライド草稿は Markdown で出力する。論文読み会の資料をページ単位まで具体化する場合は、原則として次の形式を使う。

以下は架空の手法と文献を使った例である。

```markdown
# 11. 提案手法

## 提案手法 2/4 | 候補を事前に絞って推論量を削減

### 二段階の候補選択

- QueryRank [Yamada+ ACL’25] は第 1 段階で候補を 100 件から 20 件へ圧縮
- 第 2 段階で残った 20 件だけを詳細に評価
- NDCG: 0.412 [Yamada+ ACL’25, Table 2]

➜ 精度を保ちながら推論時の計算量を削減

**図・表**

- Figure 3
- Figure from [Yamada+ ACL’25]

**出典**

- [Yamada+ arXiv’25, Sec. 3.2, Fig. 3, Table 2](https://arxiv.org/abs/<arXiv-id>)
```

- `# <番号>. <節または役割>` でスライドを区切り、直下に `## <節> | <そのスライドで扱う対象>` のタイトルを書く。
- 必要に応じて短い小見出し、箇条書き、数式、`➜` による小結論、原論文の Figure / Table / Equation 番号を置く。
- 本文では引用対象の直後に短い引用を置き、各スライドの最後にリンク付きの `**出典**` を置く。両者は役割が異なるため、末尾のリンクで本文中の引用を置き換えない。
- 構成だけを求められた場合は、節・スライドタイトルと、対応する原論文の section / subsection の粒度までに留めてよい。

最初から総枚数を決めない。まず section、subsection、独立した主要結果、application、ablation など、原論文の一つの説明単位ごとに候補を作る。その後、既存資料の情報密度や段階表示を考慮して統合・分割し、最終的な枚数感を確認する。
