# Send only into an empty input

Build every peer prompt in a shell variable first (for example, with a quoted heredoc) and pass it as one argument; never let the shell expand task or report text.

Before every prompt send in this skill, run the guarded sender at ~/.agents/skills/shunk031-herdr-orchestrate-workers/scripts/herdr-agent-prompt-if-input-empty.sh with the target and a quoted message variable instead of calling herdr agent prompt directly. The helper resolves the target pane with herdr agent get, reads herdr pane read <pane-id> --source visible --format ansi, and uses herdr agent prompt as the transport only when the current ❯, ›, or Antigravity CLI > input line has no non-dim text. Treat placeholder or suggestion text styled with ANSI \e[2m or the 256-color gray foreground \e[38;5;8m after the prompt glyph as empty; any other styling there, including \e[90m, counts as occupied. It checks immediately, then waits 30 seconds and rechecks up to five times; if the input remains occupied or cannot be read, it leaves the message unsent and prints the full message as undelivered.
